# /prompts:cxt-load

Restore a saved CXTHub ref to a provider-compatible session or memory form.

**Execution**: explicit `cxt` CLI

Usage: `/prompts:cxt-load [ref] [--provider claude|codex] [--mode
full|reconstructed|memory]`. Run `cxt load` through the shell and report the
actual fidelity and resume command. For read-only inspection instead, use
`context_fetch`.
