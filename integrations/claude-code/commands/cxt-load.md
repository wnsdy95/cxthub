# /cxt-load

Restore a saved CXTHub ref to a provider-compatible session or memory form.

**Execution**: explicit `cxt` CLI

Usage: `/cxt-load [ref] [--provider claude|codex] [--mode
full|reconstructed|memory]`. Run `cxt load` through the shell and report actual
fidelity and resume guidance. Use `context_fetch` for read-only inspection.
