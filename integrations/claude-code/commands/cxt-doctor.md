# /cxt-doctor

Find what does not fit between the sessions on this computer and the server.

**Execution**: explicit `cxt` CLI

Usage: `/cxt-doctor`. Run `cxt doctor` through the shell. The command reads
this computer and the server and changes nothing. Report every finding with
its code, what it says, and the command it gives to put the matter right. A
finding does not make the command fail. Do not run a command that removes or
archives a session unless the user asks for it.
